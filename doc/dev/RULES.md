# Development Rules
1. Mějte logiku oddělenou od UI (Views vs Core).
2. Jakékoliv texty v UI musí být lokalizované do všech podporovaných jazyků (CS, EN).
3. Do CHANGELOG.md zapisujte každou změnu funkcionality (přidání, úprava, smazání).
4. Pro verzování používejte sémantické verzování a formátujte changelog podle Keep a Changelog.
